# OCAP 业务点列表 —— 国际国内先进标准对标

> 本文档对标 **国际半导体制造标准 (SEMI)、智能制造集成标准 (ISA-95)、质量合规标准 (ISO/IATF/FDA)、工业4.0参考架构 (RAMI 4.0)** 以及 **国内智能制造标准体系 (GB/T、智能制造能力成熟度模型)**，系统化梳理 OCAP 系统的业务点列表，作为产品规划与研发实现的最高纲领。

## 四、国内国际对标对比

### 4.1 OCAP 系统与国际先进对标

| 维度 | 应用材料 SmartFactory Knowledge Advisor | 本项目 OCAP | 对标差距/策略 |
| :--- | :--- | :--- | :--- |
| 核心定位 | 工程智能 (EI) 系统核心组件 | 同左 | 一致 |
| SPC/FDC 集成 | 深度集成 E3 生态 | 标准 SEMI 接口集成 | 通过标准化接口实现解耦，降低集成耦合度 |
| 工作流引擎 | 集成工作流引擎 | 独立工作流引擎（BPMN 2.0） | 采用开放标准，避免厂商锁定 |
| AI 能力 | CPM 上下文模式匹配 | CPM + ML 根因推荐 + 知识图谱 | 扩展 AI 能力，引入知识图谱 |
| 数据生态 | E3 系列数据 | SEMI 标准 + 开放 API | 通过开放标准扩大生态兼容性 |
| 合规审计 | GEP、企业审计标准 | + 21 CFR Part 11 + IATF 16949 8D | 增强汽车/医药等强监管行业合规 |
| 人为错误降低 | 目标降低 50% 报废 | 同左 + 量化 KPI | 建立量化指标体系 |

### 4.2 国内对标要点

| 维度 | 国内现状 | 本项目策略 |
| :--- | :--- | :--- |
| 智能制造成熟度 | 多数晶圆厂处于 GB/T 39116 二级（已打造）至三级（优化）阶段 | 对标三级以上要求，支撑成熟度提升 |
| 国产化替代 | SEMI 标准主导，国产标准 SJ/T 系列逐步完善 | 双标准并行支持，SEMI 为主、SJ/T 为辅 |
| 数据孤岛 | 国产设备数据接入标准不统一 | 提供开放扩展机制，适配国产设备 |
| 知识沉淀 | 经验依赖专家，知识沉淀不足 | 知识图谱 + 案例库，系统化沉淀 |
| 合规要求 | 汽车芯片、消费芯片合规要求趋严 | 全链路审计 + 8D 报告 + 电子签核 |

## 五、业务点优先级与实施路线

### 5.1 优先级定义

- **P0 (Must-Have)**：MVP 必备，无此功能系统不可用
- **P1 (Should-Have)**：核心增强，MVP 后首要迭代
- **P2 (Nice-to-Have)**：高级能力，中长期演进

### 5.2 实施路线

| 阶段 | 范围 | 涉及业务点 | 目标 |
| :--- | :--- | :--- | :--- |
| **Phase 1: MVP** | 异常感知 + 引导式排查 + 处置闭环 | BP-A P0、BP-B P0、BP-C P0、BP-D P0、BP-E P0、BP-H P0、BP-G-01/05 | 打通核心闭环 |
| **Phase 2: 增强** | 知识管理 + 分析改进 + 集成扩展 | BP-F P0/P1、BP-G P1、BP-E P1、BP-D P1 | 知识沉淀与持续改进 |
| **Phase 3: 智能** | AI 能力 + 知识图谱 + 预测 | BP-C P1/P2、BP-G-08、BP-F-02/05 | 智能化升级 |
| **Phase 4: 平台化** | 多租户 + 扩展机制 + 移动端 | BP-I 全部、BP-D-09、BP-F-06 | 平台化演进 |
